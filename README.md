# Draw Things Prompt Studio

Counterfeit V3.0用、日本語タグ選択式プロンプト生成ツール。GitHub Pages対応。

## 公開方法

1. GitHubの `create-prompt` リポジトリに、ZIPを解凍した**中身の4ファイル**をアップロードします（ZIPそのものではありません）。
2. `index.html` がリポジトリの最上位にあることを確認します。
3. Settings → Pages → Deploy from a branch → main / (root) → Save。
4. `https://ユーザー名.github.io/create-prompt/` をSafariで開きます。
5. 共有 → ホーム画面に追加。初回オンライン表示後はキャッシュが保持されている限りオフライン利用できます。

入力内容は端末のブラウザ内に保存されます。Safariのデータ削除等で消える場合があるのでJSONバックアップを使ってください。
